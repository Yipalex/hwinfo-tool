# HWInfoTool 硬件检测工具

一个 Windows 平台的电脑硬件信息检测小工具：单文件 EXE、绿色免安装、双击即用。
专为**远程运维场景**优化——通过远程控制软件（GameViewer、向日葵、ToDesk 等）登录目标机器运行时，依然能拿到**目标机本身**的真实硬件信息，而非远程会话的虚拟设备。

## 功能特性

- **双视图界面**
  - 「简约概览」：鲁大师风格的一页摘要（电脑名 + 处理器 / 内存 / 显卡 / 主板 / 显示器 / 主硬盘 / 网卡 7 项）
  - 「详细参数」：树形分组的完整硬件清单（9 大类，含 BIOS、分区、出厂日期、序列号等）
- **一键复制**：按当前页签复制摘要或完整报告，纯文本对齐排版，可直接粘贴到微信/文档
- **导出报告**：生成 `.txt` 文件，文件名自动包含计算机名与时间戳
- **全面容错**：任何单项检测失败显示「未知 / 未检测到」，不报错、不崩溃；普通用户权限即可运行
- **远程会话感知**：自动识别并过滤远程软件的虚拟显卡 / 虚拟显示器 / 虚拟网卡，并标注真实物理硬件的连接状态

## 支持环境

| 项目 | 说明 |
|---|---|
| 操作系统 | Windows 7 / 8 / 10 / 11 |
| 架构 | 32 位、64 位均可（发布版为 32 位构建，天然兼容两者） |
| 运行权限 | 普通用户即可；管理员权限下信息更完整 |
| 依赖 | 无任何依赖，单 EXE 运行，不写注册表、不写系统目录 |

## 使用步骤（使用者）

1. 获取 `HWInfoTool.exe`（单文件，约 10 MB），拷到目标电脑任意位置；
2. 双击运行，等待 1~2 秒自动完成检测；
3. 默认显示「简约概览」，切到「详细参数」可查看完整信息；
4. **复制当前页**：把当前页签的内容复制到剪贴板；
5. **导出报告**：保存为 `硬件检测报告_计算机名_YYYYMMDD_HHMMSS.txt`；
6. **重新检测**：更换硬件后点击刷新。

> 首次启动稍慢 1~2 秒属正常现象（单文件 EXE 自解压到临时目录，退出自动清理）。
> 若杀毒软件误报，添加信任即可——这是 PyInstaller 打包程序的常见误报。

## 开发环境（打包者）

| 项目 | 版本要求 | 原因 |
|---|---|---|
| Python | **3.8.10（32 位）** | 3.8 是最后一个支持 Windows 7 的版本；32 位构建同时兼容 32/64 位系统 |
| pywin32 | 306 | WMI / 注册表 / Win32 API 访问 |
| PyInstaller | 5.13.2 | 6.x 已放弃 Win7 支持 |

> 安装 Python 时务必勾选 **Add Python to PATH**。

## 打包步骤

把 `hwinfo_tool.py` 与 `build.bat` 放在同一目录，**双击 `build.bat`**（无需管理员权限）：

```bat
python -m pip install pywin32==306 pyinstaller==5.13.2
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name HWInfoTool --hidden-import pythoncom --hidden-import pywintypes hwinfo_tool.py
```

产物位于 `dist\HWInfoTool.exe`。

## 技术要点

- **WMI 访问**：直接使用 pywin32 的 `SWbemLocator` COM 接口，不经过 moniker 解析——第三方 `wmi` 库在 PyInstaller 冻结后会报 `0x800401E4`；
- **显存**：WMI 的 `AdapterRAM` 是 32 位有符号整数（>4GB 溢出），改为读取注册表 `HardwareInformation.qwMemorySize` 的 64 位真实值；
- **显示器**：解析注册表 `Enum\DISPLAY` 下的原始 EDID（型号、序列号、出厂年周、物理尺寸），并用 `EnumDisplayDevices` 区分「物理连接 / 远程虚拟镜像 / 历史记录」；
- **远程会话过滤**：显卡仅保留 PCI 总线设备，网卡按关键词排除虚拟适配器，NVMe 接口按 PNP ID 修正（WMI 常误报 SCSI）。

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 打包报 `WinError 5 拒绝访问` | 旧版 EXE 正在运行。新版 build.bat 已自动 `taskkill`，手动打包请先关闭程序 |
| build.bat 里命令变成乱码 | bat 被存成了非 ASCII 编码。cmd 按 GBK 解析，脚本必须保持纯英文 |
| 显示器型号与本机不符 | 远程会话的虚拟显示器会镜像操作端 EDID。本工具已标注状态，认准「物理显示器」条目 |
| 显卡分辨率显示 1024×768 | 远程会话下的正常现象，本机实际输出以物理显示器为准 |
| 个别字段显示「未知」 | 硬件/驱动未上报该字段（如品牌机主板序列号为空），属正常 |
